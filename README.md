# Lions du Sénégal — Football Team Management

Application de gestion d'une équipe de football, développée avec **React**, **TypeScript** et **Tailwind CSS**.

## Fonctionnalités
- Dashboard avec statistiques et graphiques (Recharts)
- Gestion des joueurs (ajout, modification, suppression, consultation)
- Recherche et filtrage des joueurs
- Navigation multi-pages avec React Router
- Interface responsive (mobile, tablette, ordinateur)

## Installation
\`\`\`bash
npm install
npm start
\`\`\`

## Stack technique
- React JS + TypeScript
- Tailwind CSS
- React Router
- Recharts
- Lucide React (icônes)
